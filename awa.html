A product of my own

awa

A mobile app that asks how your apps make you feel.

The idea

Screen-time tools track duration; Awa tracks emotional impact. It introduces a qualitative feedback loop to digital well-being by prompting people to map specific positive or negative emotions to their usage.

Over time, it surfaces clear behavioural patterns, so people can audit their digital habits based on underlying sentiment rather than just minutes.

For businesses, it unlocks anonymised, aggregate sentiment telemetry, helping teams evaluate product-market resonance without compromising individual privacy.

Where it comes from

Where it comes from

Awa is the productisation of my research in Emotion-Driven Innovation (published via Springer, 2024).

The underlying framework shifts emotion from an accidental byproduct of UX to an intentional, measurable design metric.

Awa is the live execution of this theory: moving past raw behavioural analytics to capture explicit emotional vectors.

How it works

  1. 01 Values Figma variables ⇄ and src/theme

    Colour, type, spacing, radius and motion live as Figma variables and as code tokens with the same values. Raw values are only allowed in one place.

  2. 02 Meaning DESIGN.md

    A plain-text file explains what the tokens can't: green always means good and peach means not so good, which component to use when, and the product rules. Claude reads it at the start of every session.

  3. 03 Routine awa-ui skill

    A skill sets the order of work. New screens start with a plan or a few proposals, then the build, the checks, and a look in the simulator.

  4. 04 Checks awa-design-audit skill + audit-a11y script

    The skill checks the design system and the script checks accessibility (WCAG 2.2 AA). Both run on every change. When code moves ahead of Figma, the change goes on a list so the file catches up in batches.

Accessible by default

Awa follows WCAG 2.2 AA and Apple's Human Interface Guidelines. The audit found four colours that were too light for text, and I darkened them just enough to pass while keeping the warm palette.

  • 44pt touch targets Every tap area is at least 44 by 44 points.
  • Larger text Text grows with the iPhone's text size setting, and layouts grow with it.
  • VoiceOver Every control says what it is, and the dot charts read their numbers aloud.
  • Reduce Motion With Reduce Motion on, animations step aside and show the end state.
